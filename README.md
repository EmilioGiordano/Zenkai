# Zenkai

Native, lightweight, open-source desktop spreadsheet that opens and edits `.xlsx`
files, built in Rust with GPUI and designed to behave like Excel.

Status: project setup. No code yet; Phase 0 (engine benchmark) comes next.

- Product spec: `docs/SPEC.md`
- Rules for contributors and agents: `AGENTS.md`
- Decision log: `DECISIONS.md`
- Ideas backlog: `docs/IDEAS.md`

Build, test and benchmark instructions for Windows will be added together with the
Cargo workspace.
