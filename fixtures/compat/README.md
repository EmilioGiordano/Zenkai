# Compatibility corpus

Every file here is opened by `zenkai-bench compat fixtures/compat docs/COMPATIBILITY.md`,
which regenerates `docs/COMPATIBILITY.md`. Add the file of every compatibility bug here.

- `*.xlsx`: generated by `zenkai-bench compat-generate fixtures/compat` (rust_xlsxwriter),
  one feature per file, formulas with their cached values.
- `issues.xls`, `issues.ods`, `date.xls`: from calamine's test suite
  (https://github.com/tafia/calamine, MIT license), used for the read-only fallback.

Still missing: files saved by Excel (Windows and Mac), Google Sheets, LibreOffice, Numbers,
openpyxl, PhpSpreadsheet and Apache POI.
