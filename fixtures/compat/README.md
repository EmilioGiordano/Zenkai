# Compatibility corpus

Every file here is opened by `zenkai-bench compat fixtures/compat docs/COMPATIBILITY.md`,
which regenerates `docs/COMPATIBILITY.md`. Add the file of every compatibility bug here.

- `*.xlsx`: generated by `zenkai-bench compat-generate fixtures/compat` (rust_xlsxwriter),
  one feature per file, formulas with their cached values. For the content kinds
  rust_xlsxwriter does not write (`bench/src/compat_kinds.rs`), the file is its output with
  the parts and elements Excel writes for that kind added by hand.
- `issues.xls`, `issues.ods`, `date.xls`: from calamine's test suite
  (https://github.com/tafia/calamine, MIT license, see `LICENSE-calamine-MIT.md`), used
  for the read-only fallback.

Still missing: files saved by Excel (Windows and Mac), Google Sheets, LibreOffice, Numbers,
openpyxl, PhpSpreadsheet and Apache POI, and Excel files with a data model (Power Pivot) or
slicers and timelines, whose parts cannot be written reliably by hand.
