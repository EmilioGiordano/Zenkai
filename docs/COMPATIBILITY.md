- **Warned on open**: what Zenkai detects and warns about before saving.
- **Dropped by save**: what actually disappears from the file Zenkai writes (by part name, top-level element or key attribute).
- **Dropped without warning**: what of that has no warning; the corpus test fails unless it is empty.
- **Cached = recalculated**: each value saved in the file (read with calamine) against the value Zenkai shows after recalculating.
- **Round trip**: save, reopen and compare every filled cell.
